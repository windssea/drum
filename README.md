# 鼓点练习场 · DRUM LAB

在平板上打开 [鼓点练习场](https://drum.nanokid.win/)。可以接 USB MIDI 电子鼓、多指点按屏幕或使用键盘。每课先点「听示范」，再点「开始跟练」。四拍预备之后开始计分。「节奏格」从左到右读谱，同一列的鼓一起敲。「落点」提供向击打线移动的鼓轨。慢练使用约 75% 速度，保留原节奏比例。

## 鼓点游乐场

在 [鼓点游乐场](https://drum-lab.windssea526.workers.dev/#arcade) 体验 20 个原创节奏小游戏。菜单可按稳拍、听音复奏、辨音留白、同拍合击和轻重控制筛选。游戏支持实体鼓、触屏和键盘。轻重关卡可点按不同鼓垫区域，键盘按住 Shift 重击。每关可听示范、慢练，并在「输入延迟校准」中微调击打判定。原速奖牌保存在当前浏览器。关卡与音乐设计见 [游乐场设计](artifacts/game-progress.md)。
## 训练课程

所有练习均为本项目编写的 4/4 拍鼓谱。一个小节存为 16 格，整拍在 0、4、8、12 格。按每课所需细分显示四分、八分或十六分格。

| 课程 | 原速 BPM | 小节 | 练习要点 |
| --- | ---: | ---: | --- |
| 底鼓与军鼓 | 65 | 4 | 第 1、3 拍底鼓，第 2、4 拍军鼓 |
| 四分踩镲 | 72 | 4 | 每拍闭镲，双肢同击 |
| 八分摇滚 | 80 | 4 | 闭镲打 1 & 2 & 3 & 4 &，维持反拍军鼓 |
| 反拍底鼓 | 86 | 4 | 在第 3 拍的 & 加入底鼓 |
| 开镲与脚合 | 88 | 6 | 第 2、4 小节的 4 & 开镲，下小节第 1 拍踩合 |
| 叮叮镲与镲帽 | 92 | 4 | 八分音符镲面律动，第 2、4 拍改打镲帽 |
| 通鼓过门 | 96 | 8 | 第 4、8 小节后半的十六分过门，第 5 小节强音镲回拍 |
| 双音色复合跳 | 100 | 4 | 右手打高通，左手打军鼓，RLRR LRLL，加入底鼓 |

复合跳采用标准 single paradiddle 手序，以两种鼓声呈现左右手。判定使用击打的鼓位和时间。同拍多鼓分别判定，已命中的音符只计一次，漏击和多击都会打断连击。命中率为「命中 ÷（命中 + 漏击 + 多击）」。[Percussive Arts Society 基本功目录](https://pas.org/rudiments/)

## 连接罗兰电子鼓

通过 USB 或 MIDI 接口连接音源模块，点击「连接电子鼓」并允许访问。Web MIDI 需要支持该功能的浏览器及 HTTPS，本机开发可用 localhost。在「鼓位映射」中可选择输入端口、检查最近的音符及力度、敲击学习或手工输入编号，绑定保存在本机浏览器。自由打击保留每个打击区的名称。课程中普通闭镲、开镲及对应强音镲接受同一镲的镲面或镲边。

默认使用 TD-17 的 24 个打击区。其他模块或自定义套鼓可直接学习自己的编号。普通跟练时，实体鼓由模块发声；触屏、键盘和听示范使用网页合成的鼓声。[Roland TD-17 官方音符表](https://support.roland.com/hc/en-us/articles/39437297510683-TD-17KV2-Default-MIDI-Note-Map)

| 鼓件 | MIDI 编号与区域 |
| --- | --- |
| 底鼓 | 36（兼容 35） |
| 军鼓 | 38 鼓面，40 鼓边，37 横击 |
| 高／中／落地通鼓 | 48／45／43 鼓面，50／47／58 鼓边；落地通鼓兼容 41 |
| 踩镲 | 42／22 闭镲面／边，46／26 开镲面／边，44 踏板 |
| 强音镲 1、2 | 49／55、57／52，各自为镲面／镲边 |
| 叮叮镲 | 51 镲面，59 镲边，53 镲帽 |
| AUX | 27 鼓面，28 鼓边 |

## 歌曲实验 · 两只老虎（Frère Jacques）

采用传统公版旋律，重新编写 C 大调的旋律、贝斯、和声及鼓轨，自行合成伴奏。示范播放伴奏加参考鼓，跟练播放去鼓伴奏。歌曲保持编曲原速。[旋律来源与公版说明](https://playdacapo.com/pieces/trad-frere-jacques)

从本版多轨 MIDI 读取 480 PPQ、每四分音符 750,000 微秒和 4/4 拍号，得到 80 BPM，每拍 750 毫秒，每小节 3 秒。提取通道 10 的有效起音、力度及鼓号，换算成十六分格位置。第一个鼓点在音频 0.000 秒，四拍预备在音频开始前播放。全曲 8 小节、24 秒、70 次独立击打。鼓点来自本次编曲的独立鼓轨。

| 时间 | 小节 | 鼓谱 |
| --- | --- | --- |
| 0–12 秒 | 1–4 | 每拍闭镲；1、3 底鼓，2、4 军鼓 |
| 12–18 秒 | 5–6 | 配合更密的旋律改用八分闭镲，底鼓与军鼓维持原位 |
| 18–21 秒 | 7 | 回到四分闭镲 |
| 21–24 秒 | 8 | 前两拍沿用基本节奏，第三拍底鼓加强音镲（22.5 秒），第四拍留空 |

可在歌曲页听示范、翻小节或下载 MIDI。歌曲文件在 `public/songs/frere-jacques/`，包括 `arrangement.mid`、`backing.flac` 和 `chart.json`。重建实验需 Node.js 和 FFmpeg，运行 `node scripts/build-demo.mjs`。

## 本地开发与部署

```sh
npm ci
npm run dev
npm run build
npx wrangler deploy
```

Wrangler 会重新构建并把静态文件发布到 `drum.nanokid.win`。演示歌曲目前随 Worker 静态资源发布。未来迁移到 Cloudflare R2 时，保持 `songs/frere-jacques/` 对象目录，在构建环境设置 `VITE_SONG_BASE_URL=https://<音乐域名>/songs` 后重新部署即可。跨域读取谱面和伴奏需要 R2 CORS 允许来源 `https://drum.nanokid.win` 的 GET 请求。生产文件服务可使用绑定到 R2 的自定义域名。[Cloudflare R2 自定义域名](https://developers.cloudflare.com/r2/buckets/public-buckets/) · [R2 CORS](https://developers.cloudflare.com/r2/buckets/cors/)
