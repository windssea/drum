# 游乐场验证记录

- `npm run build` 完成 TypeScript 检查及 Vite 生产构建。小游戏独立加载，JavaScript 压缩后约 16 kB，封面 WebP 约 96 kB。原训练课程的 Three.js 舞台继续按需加载。
- `node --experimental-strip-types --test tests/*.test.mjs` 的 10 项测试通过，覆盖 20 张谱面、提示与复奏的重合、低音留白、同拍窗口、力度、校准及原有课程判定。
- 本地生产预览用 Chrome 在 1024×768 平板布局下逐关启动、停止和示范。以 Web Audio 的预备拍为起点，通过模拟 Web MIDI 打完全部 20 关，逐关校对判定数，再检查忙碌关卡在 768×1024 布局中的触控区。完整自动通关测试使用加速时钟。
- 另用实际速度完成《合闸调频》《力度印刷厂》《卫星回声》，分别命中 78、15、14 个音符，零漏击、零多击，帧间隔的第 95 百分位为 13.8–13.9 ms。这是本机 Chrome 的浏览器计时结果。实体电子鼓的传输延迟及平板硬件帧率需要实际设备测量。
- 场景用一层 Canvas 2D 绘制，静态背景预渲染，画布设备像素比例上限 1.5，绘图像素预算约一百万。场景与鼓击回馈依照音频时钟的绝对时间，每帧读取状态，判定不取决于帧数。
