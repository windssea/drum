# 轰壳蟹 · 破浪重砸

## 鼓手与战场

独立海港底景上叠着鼓船、轰壳蟹和交锋特效。普通落槌在四个姿势里切换，鼓槌接触鼓面时出现墨线爆点，首领同时受力回弹。合击在同一个动作内累加力度。重招只让角色短暂停在接触姿势，音乐、输入和下方谱面的游标继续走拍。

重锤的金锚向甲壳砸下，连射沿三条错开的弹道接连命中，碎浪向两边扯开紫色壳片，格挡先在船前顶住来击再反射回去。重击背后的海面短暂压暗，笔触朝撞点汇聚。开启系统「减少动态效果」时，Web 版收起镜头震动和速度线。

## 轰壳蟹来袭

敌人右钳举起、钟壳后倾，随后向玩家一侧前扑，在落点打出紫色冲击环。听到重音时已经看见钳尖落下。收招继续摇动旗帜，直到重心回到原位。
