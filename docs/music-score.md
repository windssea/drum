# 《鼓浪回击》配乐与起音

《鼓浪回击》是轰壳蟹首战的原创器乐曲。它用干脆的底鼓和军鼓把节拍立起来，电贝斯在鼓的空档接话，铜管以 D–F–A–G 的切分动机带出有点莽撞的海兽。主曲为 **4/4、16 小节**。演出版 96 BPM，每拍 625 ms，共 40 秒。慢练版 72 BPM，每拍约 833.333 ms，共 53.333 秒。两个速度都使用 D 小调、同一旋律音高及同一套乐器。

## 乐段

每轮分为「侦察 → 自由出招 → 听敌招 → 定拍防守」。伴奏底鼓固定落在 1、3 拍。侦察与听招用右声道偏上的短木音标出 2、4 拍，踩镲只轻点四分脉冲，给真实的军鼓、通鼓示范留位置。由玩家出招或防守时，软军鼓接过 2、4 拍。装饰军鼓、通鼓花点和连续的碎镲从伴奏中移除。听 RLRR LRLL 这样的十六分手序时，整小节的每一次军鼓或通鼓示范都由关卡单独调度。下面的时间按 96 BPM 列出。

| 时间 | 小节 | 段落变化 |
| --- | --- | --- |
| 0.000–10.000 秒 | 1–4 | 先给 D 小调切分主旋律。底鼓在下拍落稳，军鼓支撑二、四拍，结尾转向 A7。 |
| 10.000–20.000 秒 | 5–8 | 主旋律被加倍的铜管和推拍贝斯接起，借 B♭maj7 打开色彩。危险阶段拉开声部间距。 |
| 20.000–30.000 秒 | 9–12 | 进入关系大调 F 的过桥，延续动机轮廓。Cadd9 与 B♭ 把旋律带回 A7，给最后一轮留出张力。 |
| 30.000–40.000 秒 | 13–16 | 铜管高八度回归，句尾用 C♯ 引回 D。第 16 小节第四拍的低鼓、合奏与镲形成完整收束。 |

## 重建和验证

Google Antigravity 本地 CLI 提供原创的四音动机草案及过桥建议。项目内用 [build-battle-score.mjs](../scripts/build-battle-score.mjs) 确定实际和弦、节奏、音色合成、房间反射和压缩输出。音频全由可重建的合成代码生成。

需 Node.js 与含 libvorbis 的 FFmpeg。在仓库根目录运行

```sh
node scripts/build-battle-score.mjs
ffprobe -v error -show_entries stream=codec_name,sample_rate,channels,duration game/music/battle.ogg
ffmpeg -hide_banner -nostats -i game/music/battle.ogg -af ebur128=peak=true -f null -
```

### 速度与音高验证

使用 FFmpeg 解码 Vorbis 为 48 kHz 双声道 PCM。以各小节第一击的鼓头瞬态与首小节前 16 ms 作局部相关测量；原生前导通过去掉四拍后与同速 Web 音轨的对齐验证。

| 速度 | Web 样本帧数 | 原生样本帧数 | 原生预备帧数 | 解码下拍估算 |
| --- | ---: | ---: | ---: | ---: |
| 96 BPM | 1,920,000 | 2,040,000 | 120,000 | 95.99971 BPM |
| 72 BPM | 2,560,000 | 2,720,000 | 160,000 | 71.99984 BPM |

两种速度的独立编码版本都在去掉原生四拍前导后对齐到同一采样帧。−30 dBFS 检测到 Web 首音约 0.125 ms，原生版分别约 2,500.062 ms 和 3,333.438 ms；小节下拍的相关峰局部漂移最大 0.375 ms。所有音色由固定 48 kHz 采样率和 MIDI 音高生成，速度仅改变写入时刻和音符时值。对两条解码音轨首音的 100–250 ms 分析，铜管泛音得到同一 D4 基频约 293.45 Hz。
